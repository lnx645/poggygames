# PoggyGames 🕹️

Portal game web gratis ala Poki — main langsung di browser, tanpa instal.

## Isi
- **PoggyCraft 3D** (game utama) — game voxel 3D ala Minecraft dibuat dengan **Godot 4.3**:
  dunia balok prosedural 64×64, pohon & pantai, mode first-person, hancurkan/pasang
  balok, 7 jenis balok di hotbar, mode terbang. Sumber Godot ada di folder `godot/`.
- **Ular Klasik**, **2048**, **Flappy Terbang**, **Breakout**, **Memori Kartu** — HTML5 murni.

## Kontrol PoggyCraft
Klik layar untuk mengunci mouse • WASD jalan • Spasi lompat • Shift lari •
F terbang • Klik kiri hancurkan • Klik kanan pasang • 1–7/rol pilih balok • Esc lepas kursor.

## Deploy
Situs statis — impor repo ini ke Vercel (atau host statis apa pun). `vercel.json`
sudah mengatur header cross-origin untuk game Godot.
